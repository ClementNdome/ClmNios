## About the site

Single-page static portfolio built with plain HTML/CSS (custom design system), AOS scroll animations, and Font Awesome icons. Hosted on GitHub Pages.

SEO features:

- Semantic schema.org `Person` + `Organization` (SpatioNEX) JSON-LD with bidirectional links
- `sitemap.xml` with image extensions, `robots.txt`
- `llms.txt` for AI assistant discovery
- Open Graph / Twitter cards, canonical URL, GA4 analytics
